# Substrate Data

Одна модель данных, один текстовый синтаксис, одна бинарная форма,
упакованные кадры и одна система схем: для файлов программы, сохранений,
кэшей и сетевых сообщений. Формат описывается один раз как тип Rust; его
можно читать из текста, написанного руками (каждая ошибка со строкой и
путём), править на месте без потери комментариев, компилировать в
компактный бинарь, передавать по сокету и описывать редактору, который
строит по нему таблицу свойств.

🇺🇸 [English](README.md) | 🇷🇺 **Русский**

Спецификация формата: [docs/format.md](docs/format.md) (на английском).

| Крейт | Что это |
|---|---|
| `substrate-data` | модель, текст, бинарь, кадры, схемы, диагностика |
| `substrate-data-derive` | `#[derive(Schema)]` |

Вынесен из `yog-data` (Yog Mod Loader), всё специфичное для Minecraft и
Yog убрано, чтобы его могли использовать Meridian, инструменты и IDE на
Substrate Platform.
